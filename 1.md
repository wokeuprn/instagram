1. Cryptography & Session Utilities
Password Hashing: Implemented PBKDF2 SHA-256 secure hashing with individual salt generation in 

auth.py
.
ID Generation: Added a 63-bit secure random integer generator for PostgreSQL BIGINT primary keys to prevent autoincrement sequence guessing attacks.
2. Service (CRUD) Layers
Relational Databases (PostgreSQL via SQLAlchemy):


crud_sql.py
: Manages user accounts, active sessions, password verification, and account lockouts (15-minute lock after 5 failed login attempts).


crud_social.py
: Manages social relationships—follows (direct for public, follow-requests for private profiles), blocks/unblocks, and listing followers or following.


crud_content.py
: Controls posting, comments, reels creation, active stories retrieval (filtering for the last 24 hours), recording story views, and generating custom home feeds.


crud_messaging.py
: Implements direct conversations (1-to-1 DMs), message creation (text/media), seen markers, and emoji message reactions.
Document Store (MongoDB via PyMongo):


mongodb.py
: Handles adding/removing content likes, listing likes, and creating structured audit logs for logins, logouts, username updates, and bio changes.
3. API Routing and Integrations
Integrated all endpoints into 

main.py
 with structured Pydantic models in 

schemas.py
.
Added automatic PostgreSQL table creations on server startup and token-based dependency verification (get_current_profile).
4. Postman Collection
Configured a comprehensive Postman JSON configuration in 

Instagram_Clone_Postman_Collection.json
 mapping out step-by-step requests. Environment variables are set up to capture authentication headers, request IDs, and target IDs automatically as you run requests.
